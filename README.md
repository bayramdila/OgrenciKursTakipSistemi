# 🎓 Öğrenci – Kurs Takip Sistemi

Bu proje, C# ve SQL Server kullanılarak geliştirilmiş basit bir konsol tabanlı öğrenci-kurs yönetim sistemidir.

## 🚀 Kullanılan Teknolojiler

- C#
- .NET
- SQL Server
- ADO.NET
- Katmanlı Mimari (Services – Database)

## 📚 Özellikler

✔ Öğrenci Ekleme  
✔ Öğrenci Güncelleme  
✔ Öğrenci Silme  
✔ Öğrenci Listeleme  
✔ Kurs Listeleme  
✔ Öğrenciye Kurs Atama  
✔ Öğrencinin Aldığı Kursları Listeleme  
✔ Duplicate Atama Kontrolü  

## 🗂 Veritabanı Yapısı

- Students
- Courses
- StudentCourses (Many-to-Many ilişki)

## 🔒 Güvenlik

- Parametreli sorgular kullanılmıştır.
- SQL Injection’a karşı koruma sağlanmıştır.
- Duplicate kayıt kontrolü yapılmıştır.

## 🧠 Amaç

Bu proje, ADO.NET ile veritabanı bağlantısı, CRUD işlemleri ve many-to-many ilişki yönetimini öğrenmek amacıyla geliştirilmiştir.
